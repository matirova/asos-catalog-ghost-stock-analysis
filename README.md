# ASOS Catalog & Ghost Stock Analysis

Este proyecto realiza un análisis exploratorio de datos (EDA) sobre el catálogo de productos de ASOS. El objetivo principal es evaluar la distribución de marcas, analizar la estructura de precios e identificar el impacto económico del "stock fantasma" (productos con inconsistencias entre la visibilidad en la plataforma y su disponibilidad real).

---

##  Contenido del Proyecto

* **Limpieza y Estructuración:** Tratamiento de datos no estructurados, parseo de marcas y manejo de valores nulos.
* **Análisis de Catálogo:** Identificación de las marcas con mayor volumen de productos y distribución por rangos de precio.
* **Proyección de Pérdidas:** Cálculo de *Ghost Stock Losses* (ingresos no percibidos por fallas de inventario).

---

##  Herramientas Utilizadas

* **Lenguaje:** Python
* **Librerías:** Pandas, NumPy, Matplotlib, Seaborn
* **Entorno:** Google Colab / Jupyter Notebook

---
 ## Resultados Clave
Identificación de top marcas: Análisis del volumen de catálogo ocupado por marcas propias vs. externas.

Impacto financiero: Proyección de pérdidas potenciales asociadas al stock sin disponibilidad disponible para compra.
